# Sumit Roy | Portfolio Website

This repository contains the source code for my personal portfolio website, built as a modern, responsive one-page experience that highlights my work as a developer, AI/ML engineer, and computer vision enthusiast. The site is designed to present my background, technical skills, featured projects, experience, achievements, and contact information in a polished and professional format.

## Overview

The portfolio website is a single-page React application built with Vite and styled with a dark, editorial aesthetic. It emphasizes clarity, visual simplicity, and thoughtful motion to create a premium and modern presentation that reflects both my technical abilities and my personal brand.

The website includes:
- A polished hero section with introduction and primary calls to action
- An about section outlining education, background, and technical expertise
- A featured projects section showcasing selected work and achievements
- An experience section highlighting relevant internships and professional exposure
- A certificates and achievements section presenting recognitions and participation
- A contact section with direct links and a simple interactive form

## Tech Stack

The project is built using the following technologies:
- React.js for the user interface
- Vite for fast development and efficient production builds
- Framer Motion for smooth animations and transitions
- Tailwind CSS for modern, responsive styling
- Lucide React and React Icons for interface icons

The application is organized into clearly separated sections:
1. Hero

Each section is implemented as a modular component, making the website easy to maintain and extend.

## Installation and Running Locally

To run the project locally, use the following commands:

```bash
npm install
npm run dev
```

This will start the development server and allow you to view the website in your browser.

## Build

To create a production build:

```bash
npm run build
```
